Part 2 of 4 Threshold Logic

🔀 Selection Structures: if, elif, else

A quiz grading engine—or a sensor alarm on a PLC/robot cell—must react differently to distinctions, passes, and re-attempts. Selection structures control which code block runs when a condition is True or False.

Conditions, colons & 4-space indentation

Python uses a colon (:) to open a block and 4-space indentation to group statements inside it. In an if / elif / else ladder, Python tests conditions top-to-bottom and runs the first true branch.

OperatorMeaningExample
>= / <=At least / At mostscore >= 50
== / !=Equal / Not equalgrade != "Fail"
and / or / notCompound boolean logicscore >= 80 and portfolio_ok
⚠ Watch indentation carefully. Unindented lines run unconditionally; inconsistent spacing triggers an IndentationError.

Example: Tiered grade assignment

score = 82

if score >= 80:
    grade = "Distinction"
elif score >= 50:
    grade = "Pass"
else:
    grade = "Fail"

print(grade)
Explain it like I'm 6 Imagine a row of doors with signs on them. You check the first door: if the sign matches, you walk through and ignore the rest. Only if no earlier door opened do you take the else door.

🔁 Lists & Loops: Iteration Structures

When handling a whole batch of quiz scores or sensor readings, lists group items together and loops repeat operations cleanly without copy-pasting lines.

Lists, indexing & for / while loops

A list stores an ordered collection inside square brackets [ ]. Its first element is at index 0.

marks = [62, 88, 45, 91]
# Index:   0   1   2   3
print(marks[0])    # 62
print(len(marks))  # 4
marks.append(75)   # adds 75 at the end
Explain it like I'm 6 A list is a row of numbered lockers starting at Locker 0. A for loop opens each locker in order and runs your instructions on whatever is inside.
